# running-form

Video-based running form analysis for two athletes:

| Athlete | Event | Goal | Analysis focus |
|---|---|---|---|
| **A — jumper** | Long jump (right-foot takeoff) | 22 ft (6.71 m); PR 19'3" | Max-velocity sprint mechanics, tailored to an elastic, technique-based long jumper |
| **B — miler** | Mile | — | Economy at mile pace + speed mechanics for the kick |
