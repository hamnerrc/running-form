# Instructions for agents

This repo is a running-form analysis project. **Read [README.md](README.md) in full before doing anything.** It's the brief: athletes, filming setup, data layout, the analysis pipeline, output format, and rules.

- New session data lands in `data/<YYYY-MM-DD>/`. Check it against `session.yaml` first and report anything missing.
- Results go to `results/<YYYY-MM-DD>/`. Update the status checklist in README §8 when done.
- Raw videos and photos are git-ignored. Commit code, yaml and results only.
- Never fabricate measurements. State uncertainty on every number.
